start language dictionary

type:abstracts

*-> abstract     - the declaration of a pure concept (idea) that defines the general properties and behavior for a group or single of future entity but prohibits the creation of an instance of itself
    -> exm: &-> abstract(act id="Etalon ->  get(obj) as ref")

*-> as           - creates a variable/alias binding: expression + as + name makes the object available under that name
    -> exm: crt file="action.dict" as file_action

*-> blueprint         - blueprint, base logical abstract pattern, Behavioral Model for Enforcement, Behavioral law to apply, Always true and serves as the instruction for use, unless explicitly stated or red
    -> exm:blueprint:behavior

*-> proto, prototype        - prototype property of any entity use RAG to search base prototype or use &-> to include prototype in specs
type:behavior

*-> &->          - remember this

*-> arc,arch,architect,architecture - architecture, example: func name="upload_photo" arc:coroutine; describes a function with the coroutine pattern
    -> exm:arc:coroutine

*-> behavior, bhvr     - logical mapping of behavior of any entity
    -> exm: panel:location=up restriction=frame:size * 0.25 bhvr:stretch

*-> bhvoper    - behavior pattern operator
    -> exm: bhvoper:"stretch" alias stretch 
            panel:location=up restriction=frame:size * 0.25 bhvr:stretch 
    -> exm: bhvoper:"solid" alias solid 
            code:style:rule=code:style:rule+(solid);

*-> blplan         - blueprint plan: formal plan artifact (stricter form of proto), pulled by incld="<id>", written to plan/ 
    -> exm: proto file:type = [xml,doc,txt]
            proto file:type:name = [n]  it is add property to file, example usage: file:xml:"main.xml"

*-> crit, critical  - logical critical instruction, behavior pay special attention and more-check.
    -> exm:crit:err

*-> dry          - do not repeat yourself
    -> exm:dry:true

*-> enter        - user input: enter key, confirm/select
    -> exm:on enter->btn name="ok"

*-> evt,event    - event base logic operator
    -> exm: evt:notify -> show()
    -> exm: event:onCreate -> load(view name="main")

*-> factor,          - coefficient, factor, percentage need for logical syntax [min,max]
    -> exm: llm:skill:cretive = factor[0,100]:pan(20)

*-> fbd, forbinden  - Forbidden
    -> exm:fbd:null

*-> invar, nvariant - invariant
    -> exm:inv:true

*-> isol,isolate  - An entity isolated from external logic blocks does not accept higher-level logic as the primary source.
    -> exm:crt prj name "example" type="exe" lang:c++
             -> {any custom or DSL blocks}
             -> crt lib type="dll" isol          Isolating the marker means that the context and logic of the parent program must not affect the module.

*-> kbd, key     - keyboard key: physical/logical key identifier used by input events
    -> exm:on kpress:key="Enter"->run
    -> exm:on kdown:kbd="Space"->player:jump

*-> kdown        - user input: key pressed down event
    -> exm:on kdown:key="A"->kpress

*-> kpress       - user input: key press (down+up) event
    -> exm:on kpress:key="Enter"->run

*-> kup          - user input: key released up event
    -> exm:on kup:key="Shift"

*-> mosdown      - user input: mouse button down event
    -> exm:on mosdown:btn="right"->dlg

*-> mosup        - user input: mouse button up event
    -> exm:on mosup:btn="left"->tgl

*-> pattern      - programming or behavioral pattern
    -> exm:pattern:"observer"

*-> proctx, thread  - process, context,isolate thread
    -> exm:proctx:thread

*-> scrtap       - user input: screen tap event
    -> exm:on scrtap:x=10,y=20

*-> skl, skill  - logical representation of a skill 
    -> exm:skl:code="middle"

*-> smbls         - predict array of symbols
    -> exm:smbls:["a","b"]       instruction of use only symbols a and b, need to direct syntax rule in all lang

*-> swap         - UI logical behavior: swipe / page turn between views, default direction left to right unless otherwise specified
    -> exm:on swap:dir="ltr" -> pag name="next"
    -> exm:swap:dir="rtl" -> pag name="prev"
