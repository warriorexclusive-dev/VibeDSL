# SYMBOLS EXTENDED for the VibeDSL dictionary (proposed)
# 2026-09-25 — candidates for the remaining dictionary words (not covered by
# the base symbol set in RULES). One unique standard glyph per word.
#
# Rules applied:
#   - standard Unicode blocks ONLY (no emoji 1F300-1FAFF, no CJK, no Cyrillic
#     homoglyphs, no combining marks, no currency signs - e.g. no ruble sign
#     which carries a million unrelated meanings).
#   - allowed ranges: 00A0-00FF Latin-1 (punctuation/maths signs only - ¶, ×,
#     etc.; NO currency symbols - those are a separate rule), 2000-206F,
#     2030-2057, 2100-214F, 2150-218F, 2190-21FF, 2200-22FF, 2300-23FF,
#     2400-243F, 2500-257F, 2580-259F, 25A0-25FF, 2600-26FF (non-emoji picks
#     only), 2700-27BF dingbats (non-emoji), 27C0-27EF, 27F0-27FF, 2900-297F,
#     2980-29FF, 2A00-2AFF, 2B00-2BFF, 0370-03FF Greek (only unambiguous
#     non-homoglyph letters, e.g. tau).
#   - no collision with the base symbol set or with each other (verified).
#   - KV target: one word = one atomic anchor; a symbol with 2+ RULES meanings
#     (e.g. ⪪=2) stays forbidden for new mappings.
#
# Format: U+XXXX  glyph  *-> word - mnemonic
