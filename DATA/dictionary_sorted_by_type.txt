start language dictionary

type:action

*-> act, action - action: act="desc" declares any function - standalone abstract or entity function (two canonical forms)
    -> exm: abstract "open_file" -> act="open file by name"   // declares function: open_file
    -> exm: open_file("main.txt")                             // usage
    -> exm: file:act="grant access to user":name="access"    // declares entity function: file:access
    -> exm: file:access(context:user)                         // usage
    -> exm: act==run

*-> add          - logical adding entity action 
    -> exm: xml files add to prj

*-> answ, answer - answer to user.
    -> exm:answ:->;usr
    -> exm:answ:lng=usr:lang

*-> apr, aprove  - approve
    -> exm:apr:true

*-> ask          - request; RESOLUTION ORDER: first ask the base (dictionary/syntax/protos/blueprints via RAG search/get) - if the answer is already recorded, do NOT ask again; only if the base has no answer, ask the human; never guess or invent - this frees the human from repeated questions; the constructor is a contract between human and AI, and a human can programme in this language too
    -> exm:ask:->prompt

*-> async         - action async run of any entity

*-> call         - entry / function call
    -> exm: call:fn()

*-> change,ch           - change
    -> exm:ch:->file:name

*-> close        - generic canonical act function on any entity: close(<entity>) - finalizes the entity and saves its bound node state, declared once via act, works for every entity
    -> exm: close(file name="out.xml")

*-> codrev           - code anallize, review without editing, testing
    -> exm:codrev:->src

*-> compil        - compilation, compile
    -> exm:compil:->code

*-> compress      - compress action of any entity
    -> exm: compress(llm:token)

*-> crt, create - action create: create a file, api, class, function etc. (create action; pairs with its target: crt fun, crt file, crt api)
    -> exm:crt fun name="load"
    -> exm:crt [code, data, file]
    -> exm:create fun name="load"

*-> delay,loop   - delay or period
    -> exm:delay(500) - delay 500 times
    -> exm:delay:2s   - delay 2 seconds
    -> exm:loop()     - infinite delay
    -> exm:delay()    - infinite delay

*-> deploy           - code compilation or deployment
    -> exm:deploy:->act="deploy to server"

*-> err, error   - logic action of error: a logic-stop trigger
    -> exm:fun event:err:-> ret:except:response
    -> exm:if(err)->show(excpt)

*-> extract      - extract action
    -> exm:fun crt (file name="out.xml" alias xml ): -> open(file name="project.exe"):alias source:->extract(source *? data:type=dom to xml)

*-> fun, func, function - function: an action when it is a rule or an agent; an API entry point when it is a spec or architecture; often used with the par key (parameter) and ret (return), the logic is preferably written through the language logical operators
    -> exm:fun type=rule scop=root
    -> exm:fun name="load" par="val1"
    -> exm:func name="load"
    -> exm:function name="load"
    -> exm:crt fun name="load" par="val1"
    -> exm:crt fun type="web api": par "in" type="text" desc="vibedsl request" :-> srch(in) type="RAG":-> ret

*-> get          - action to obtain any entity 
    -> exm: get:data:src

*-> incld, import, include - additional, include (logical/physical inclusion)
    -> exm:incld:->;header
    -> exm:import:module name="kernel"

*-> insert,       - logical action insert of any entity
    -> exm:insrt:row
    -> exm:if(dir:empty):insert(file)

*-> load         - load action: load a view, file or base by name
    -> exm:load(view name="main")
    -> exm:event:onCreate -> load(view name="main")

*-> make, mk           - make
    -> exm:mk:->file

*-> modify       - logic modify: modify/alter the logic (not a class/module - those are module/class)
    -> exm:mod spec:logic=spec:logic+rule

*-> move         - logical move action
    -> exm:db1:move(table)->db2

*-> only         - only, verifiication action
    -> exm:only:check

*-> open         - generic canonical act function on any entity: open(<entity>) - opens the entity bound node for changes, declared once via act, works for every entity
    -> exm: open(file name="out.xml")
    -> exm: open(user name="alice")

*-> pan, balance - action of precise correction of imprecise entities

    -> exm:return val

*-> retry        - action retry
    -> exm:retry(5)

*-> review, rvw,    - review
    -> exm:rvw:->;code

*-> trim         - action: trim/strip characters from a string or collection (default whitespace)

*-> use          - logical include command: apply/engage an object, prototype or include; the logical side of include (include is the physical lib/item, use is the logical command that engages it)
